# CodePlate plugins for Claude Code

The official [CodePlate](https://codeplate.io) marketplace for Claude Code, by IASoft.

```
claude plugin marketplace add IASoft-PVT-LTD/codeplate-plugins
claude plugin install codeplate@codeplate
```

Or run `/plugin` in Claude Code, add the marketplace `IASoft-PVT-LTD/codeplate-plugins` and install **codeplate**.

| Plugin | What it does |
|---|---|
| [codeplate](plugin/README.md) | Browse CodePlate's agent-first templates, fetch one into a new folder, run its interview and keep its checks green. |
